SCHOOL_TOOLS
一个足以改变全校的教学工具索引

专门向大连教育学院附属中学提供经过测试以及个人推荐的教学辅助应用程序，也欢迎外校前来查看，感谢智教联盟提供大量相关软件。
本人是一名高一学生（高一七班），网站于2026年11月8日正式开放
欢迎各位大佬指出问题与建议，谢谢！整理自智教联盟开源工具 · 点击项目地址直达 GitHub 仓库（可能有部分软件存在问题，可以向我或作者反馈）。
