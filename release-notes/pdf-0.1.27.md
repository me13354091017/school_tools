# SCHOOL_TOOLS_PDF 0.1.27 更新说明

发布日期：2026-11-28

该版本已下架。

## 浮动栏外观重做

- 栏体加高到 40，圆角放大到 12，阴影更柔和；按钮统一为 34×34。
- 选中态从「底部小蓝条」改成「图标 + 文字 + 整格强调色填充」：选中项整格填强调色、图标与文字反白，工具名显示在图标下方。
- 文字标签默认打开，老配置首次启动自动迁移。
- 工具按「笔 / 形状激光更多 / 撤销闪抽」分成三组，组间加 1 像素细分隔线。

## 拖动块与贴边隐藏

- 拖动块加高到 46 见方，九点更清晰，与栏体贴合更整齐。
- 整条栏拖到窗口左右边缘 12 像素以内松手，自动收起成拖动块；鼠标移到拖动块上滑出，移开 700 毫秒再收起。
- 双击栏体空白处可收起，点在工具按钮上不会误触。
